# Kaleido camera images

Source: https://github.com/m-a-x-s-e-e-l-i-g/kaleido/tree/main/site/assets

These four original 720 × 480 EOS M screen captures by Max Seelig / MAXmade were
copied unchanged from the Kaleido repository on October 21, 2026. They are lossless
WebP conversions of uncropped camera screen captures, not exported CR2 photographs
or browser illustrations.

The stonework image is used for the project card, detail-page lead image and social
preview. The remaining captures appear in the detail-page gallery.
