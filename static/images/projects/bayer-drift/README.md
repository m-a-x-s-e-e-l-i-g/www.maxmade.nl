# Bayer Drift photographs

Photographs © Max Seelig (MAXmade), copied from the Bayer Drift project's
`site/assets/photos` gallery. Photography is separate from the software GPL licence.

Source: https://github.com/m-a-x-s-e-e-l-i-g/bayer-drift/tree/main/site/assets/photos

The `city`, `bark` and `wall` examples were developed from the original Canon EOS M
camera-processed CR2 files using LibRaw/rawpy, AHD demosaicing, camera white balance,
automatic brightness and sRGB output. No synthetic glitch, sharpening or noise
reduction was added. The `*-small.webp` files are resized overviews. Each
`*-detail.png` is a matching 160 × 160 pixel crop enlarged six times using
nearest-neighbour scaling. Files are copied without modification.

The source gallery's `photos.json` records original CR2 hashes, processing settings
and crop coordinates. Capture recipes were not supplied and are not inferred.
