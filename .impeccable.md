## Design Context

### Users

Portfolio visitors discovering Max's projects, including MediaNav owners looking for project details and the repository with current installation information.

### Brand Personality

Personal, practical, creative. Present real work in clear English, with enough visual evidence to let visitors explore it.

### Aesthetic Direction

Keep the existing MAXmade style and English copy, as confirmed by the owner. Use the site's dark surfaces, restrained typography, shared project components, and real project images.

### Design Principles

- Extend the established portfolio rather than redesigning it for one project.
- Give selected work a visible place and a clear path to its detail page.
- Preserve readable layouts and accessible links on mobile and desktop.
- Distinguish interface previews from photographs of the running device.
- Keep actively developed project descriptions independent of release versions.
